# songletter-reels

Arquivos públicos dos posts do Instagram @songletter.ofc (Reels "Cartinhas de Hoje", carrosséis e stories).
O Metricool busca os arquivos por aqui (`raw.githubusercontent.com`). O gerador fica em
`NicollasGuedes30/cancao-da-vida/scripts/reels`.

- `videos/` — Reels (AAAA-MM-DD-slug.mp4 + capa .jpg)
- `imagens/` — carrosséis e stories (AAAA-MM-DD-tipo/NN.jpg)
- `postados.json` — o que já foi agendado (slug, data, tipo, id no Metricool)
